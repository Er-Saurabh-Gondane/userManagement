# User Management REST API

## 📌 Project Description

This project is a simple RESTful API built using **Node.js** and **Express.js**.  
It manages a list of users and demonstrates:

- Routing
- Middleware
- HTTP methods
- Status codes
- Error handling
- In-memory data storage

---

## 🚀 Features

- Fetch all users
- Fetch user by ID
- Add new user
- Update existing user
- Delete user
- Request logging middleware
- Validation middleware
- Proper error handling

---

## 🛠️ Technologies Used

- Node.js
- Express.js
